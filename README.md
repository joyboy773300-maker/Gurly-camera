# GirlyCam 🎀

Light, clean, Pinterest/coquette-inspired Android camera and aesthetic photo editor.

## Included
- Real CameraX live preview and capture
- Gallery photo editing
- Six aesthetic templates: Polaroid, Film, Lavender, Gingham, Minimal, Bow
- 1:1, 4:5, 3:4, 9:16 ratios
- 2–4 photo collage and export
- Real JPEG export to Pictures/GirlyCam
- Custom pink bow camera launcher icon
- GitHub Actions APK build

## Build on a phone
Push the folder to GitHub. Open Actions → Build APK → Run workflow. Download the `GirlyCam-debug` artifact when it finishes.
