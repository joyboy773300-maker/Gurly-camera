# GirlyCam v1.5 🎀

A light, Pinterest-inspired Android camera/editor.

## Included
- HD/max-quality CameraX capture (JPEG quality 100)
- Front/back camera switch
- Gallery import
- Automatic soft beauty mode with on-device ML Kit face detection
- 18 original aesthetic filters: Dreamy, Blush, Sunlit, Warm Bloom, Flash Pop, Red Light, Green Light, Cool, Lavender, Y2K, 90s, VHS, Nokia, Chrome, B&W, Film, Night Flash, Original
- Film grain, Nokia/pixel look and color-grading effects
- Original social-camera-style effects inspired by common short-form photo aesthetics; no proprietary Instagram/Snapchat assets or filters are copied
- 6 cute frames
- 1:1, 4:5 and 3:4 ratios
- 2/3/4-photo collage layouts
- Cute stickers: bow, heart, sparkle, flower, star, cloud
- Gallery export to Pictures/GirlyCam
- GitHub Actions debug APK workflow
